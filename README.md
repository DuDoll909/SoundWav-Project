# SoundWav-Project

Description: This project will allow users to share music playlists to study with each other using QR codes and have profiles to view another person's created playlists.

User Stories:

-As a user, I want to be able to like and save my favorite Playlists

-As a user, I want to see the latest and most popular playlists available

-As a user, I want to customize my playlists to make them my own

Agile Sprints:

1st sprint(1 week):
Starting wireframe to get a basic idea of how we want the website to look(Terrell)
Getting website working and adding a component that will be a playlist in the user's collection(Corbin)

2nd sprint(~1 1/2 weeks):
Adding users to test login/logout pages(Corbin)
Finishing prototype using wireframe to scope how the user will navigate through the website(Terrell)

3rd sprint(~2 weeks):
Adding feature to login/logout of website(Terrell)
Adding feature to sign-in and create account(Corbin)
Adjusting components to show proper image and detail to better illustrate playlists(Terrell)
